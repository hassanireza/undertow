## The current beneath the surface

Undertow is a studio built around one idea. Restraint is a design choice, not an absence of one. Every interface we ship carries a single clear hierarchy, considered type, and motion that earns its place. Nothing added because it was easy, nothing left in because no one questioned it.

This repository is the studio's own site. It is also, quietly, a demonstration of how we build.
